GLENIA CONTROLE

Versão com cadastro, login e dados separados por loja.

Para rodar localmente:
1. Crie/ative seu ambiente virtual.
2. pip install -r requirements.txt
3. python app.py
4. Abra http://127.0.0.1:5000

A primeira vez, clique em Criar conta.
Cada conta possui seus próprios produtos, compras, vendas e histórico.
